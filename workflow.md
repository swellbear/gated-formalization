# Operator Workflow — New Application Checklist

Use this checklist for every new claim, theory fragment, or argument you run through the method.

## 1. Setup
- [ ] Create folder `applications/YYYY-MM_short-name/`
- [ ] Copy the four templates into it (or into a `worksheets/` subfolder)
- [ ] Note the date and a short description of the source material

## 2. Anchors & Claim-Type Pre-Classification
- [ ] Fill `01_Anchor_and_ClaimType_Template.md`
- [ ] List only hard-to-dispute anchors (empirical, logical, or strong intersubjective)
- [ ] State the candidate claim / layer clearly
- [ ] Flag every major claim as **Descriptive**, **Normative/Strategic**, or **Mixed** (split if mixed)
- [ ] Confirm ready for gate scoring

## 3. Initial Gate Scoring
- [ ] Fill `02_Gate_Scoring_Sheet.md`
- [ ] Score Cons, Agree, Prod (count new non-trivial checkable consequences), Amb (list free parameters + severity weights 2/1/0.5 and sum)
- [ ] Perform higher-level review (overclaim, category error, silent meaning shifts)
- [ ] Record verdict: Admissible / Provisional / Not admissible
- [ ] Write reliability estimate and any required revisions to earlier layers

## 4. If Amb is High or Verdict is Provisional / Not Admissible
- [ ] Fill `03_Gap_Extraction_and_Ranking.md`
- [ ] List each distinct free parameter
- [ ] Score Impact / Anchor-connection / Measurability (0–2 each) and rank by sum
- [ ] Write a short search plan for the top-priority gap(s) (source classes + stopping rule)

## 5. Gap-Directed Search & Material Admission
For each piece of candidate material:
- [ ] Fill a fresh `04_Material_Admission_Check.md`
- [ ] Confirm relevance to the targeted gap
- [ ] Confirm consistency with current anchors + admitted layers
- [ ] Admit only if both clear; otherwise reject or hold
- [ ] Note expected effect on Amb and Prod

## 6. Re-score
- [ ] After any incorporation, re-fill or update the Gate Scoring Sheet
- [ ] Update annotations: what is now constrained vs still free
- [ ] Record residual judgment points encountered in this cycle

## 7. Close the Run
- [ ] Final verdict recorded
- [ ] Remaining free parameters explicitly listed
- [ ] Decision: stop / remain provisional / continue search later
- [ ] If a failure mode is visible (or later becomes visible), add entry to `logs/failure_mode_log.md`

## Reminders
- High Amb after serious search = provisional / not yet well-constrained. It does **not** equal “false.”
- New material must clear relevance + Cons before incorporation.
- Residual judgment (relevance, ranking, borderline calls, significance) stays explicit — record it.
- Prefer multiple short, honest cycles over one large unconstrained elaboration.
