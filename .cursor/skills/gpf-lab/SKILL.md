## 15m assign (`learning_lane_15m` / `KXBTC15M`)

Golf idle ON does **not** stop this Job. A CoS-assigned 15m paper PROPOSED is not golf WC3+ and is not golf idle-breach.

One PROPOSED per fire. Paper only. Handoff → `operator`. Never self-admit. Do not set `execution: true`. Do not score.

The PROPOSED note itself must contain (CoS does not wait for a separate essay):

1. **Kill anatomy** — quote the last closed score/park: which clauses failed, `skip_count` / skip region. Favorite L1 died as `n=70`, `skip_count=1`, clauses 1/4/5 fail — indistinguishable from skipping at random at that rate. Do not invent a retune of `favorite_odds` or a tape quantile (already burned).
2. **Unburned mechanism** — load [`LEARNING_LANE_15M_BURNED_CLASSES.json`](../../../golf-offshoot/docs/LEARNING_LANE_15M_BURNED_CLASSES.json) before naming a class. Re-naming a burned class is still that class. Skip-on-mark families that only move the same cut are retunes.
3. **Pre-registration** — parameters must not be informed by marks already on this tree.
4. **Live falsifier** — n and a park instruction. No retune-if-dead.
