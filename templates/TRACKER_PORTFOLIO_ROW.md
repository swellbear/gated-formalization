# Portfolio row fields (Layer 1)

Use when adding/updating a row in root `TRACKER_PORTFOLIO.md`. Tags from `docs/TRACKER_TAXONOMY.md` only.

| Field | Content |
|-------|---------|
| Application ID | Folder name under `applications/` |
| Domain tag | One primary: foundations / engineering / fiscal-legislative / markets / opinion-advocacy / AI-systems / other |
| Claim-shape | One or more taxonomy claim-shape tags |
| Pattern | Evidenced pattern tags only |
| Related applications | Max 4 IDs + one-line reason each |
| Original claim (one line) | Compressed claim |
| Successor(s) | Link/ID if any, else — |
| Final status | Admissible / Stable Provisional / Provisional / live / incomplete record |
| Established core (one line) | What held |
| Failed elevation (one line) | What did not |
| Open residuals | IDs only |
| Dissertation | Relative path to `DISSERTATION.md` |
| Thesis Tracker | Relative path to `Thesis_Tracker.md` |
| Last reviewed | Date or commit |
