# Imported-pattern stamp

**Use whenever** a lock, metric, residual definition, or process pattern is reused from a related application. Binding reuse is never automatic.

```
Imported pattern from `[application-id]`, re-validated here.
- What was imported: (lock style / metric / residual reopen / deviation lesson / …)
- Re-validation under current claim: (what was checked; what differs)
- Not inherited: verdicts, admitted layers, Amb scores from the source app
```

Paste into the lock record, `04`, evidence intake, or Phase readout where the reuse occurs.

---

*Standing rule: critically relevant surfacing — honesty constraint.*
