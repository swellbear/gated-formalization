## 0. Plain-language framing

**What we’re doing:** Listing optional tools that *could* run if you authorize them. Not required to close examination.

**What we need from you:** Nothing unless you want one.

**What authorizing means:** Runs only that mode. Does not rewrite D-LAW or turn untested “likely” into unlikely.

**What this does *not* mean:** Automatic Phase 2; that abolition is likely or unlikely; advice.

**How this differs from residuals:** Residual branches reopen a *scoped gap* on Rank 1. Optional modes are separate tools (uses, contrastive alternatives, revise wording).
