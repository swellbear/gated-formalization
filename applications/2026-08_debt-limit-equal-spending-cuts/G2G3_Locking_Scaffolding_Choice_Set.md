# G2+G3 Locking Scaffolding — Scorekeeping Choice Set (updated format)

**Date:** 2026-08-11  
**Application:** `2026-08_debt-limit-equal-spending-cuts`  
**Dominant blockers:** G2 (what “equal” means) + G3 (what counts as a spending cut / which baseline)  
**Dependents blocked:** G4 (whether unpaired debt-limit action is “fiscally irresponsible” as a descriptive verdict)

**Explicit dependency:** G4 and any workable “equal cuts over the decade” test are currently blocked primarily by the unset status of G2 and G3.

**Original claim (verbatim):**  
“Any increase or suspension of the federal debt limit must be accompanied by equal spending cuts over the following decade. Without that balance, debt-limit increases are fiscally irresponsible and should not be enacted.”

**Status:** AWAITING OPERATOR SELECTION

---

## 0. Plain-language framing

**What decision is being made right now:**  
You are choosing the **accounting rules** that would define “equal spending cuts over the next decade” — how much is enough, what counts as a cut, and against which budget forecast.

**Why this decision is required before further work:**  
Without those rules, the claim’s “balance” requirement and any later charge of “fiscally irresponsible” cannot be checked in a definite way. The method already marked that gap as the main blocker.

**What becomes testable once the decision is made:**  
Whether a given debt-limit bill, under those fixed rules, does or does not come with matching decade cuts — and, under that same yardstick, whether “no balance” can be described as failing a **stipulated** responsibility test (still not an unrestricted moral verdict).

**What still cannot be settled by this decision alone:**  
That Congress **must** use this rule; that unpaired increases are irresponsible in every sense; or that they **should not be enacted**. Those remain value/advocacy questions. Also unsettled: how large default/disruption risks are if pairing blocks a timely debt-limit vote.

## 2. Options (ordinary terms)

### E — Measuring “equal”
| ID | Meaning |
|----|---------|
| E1 | Add up ordinary dollar cuts over 10 years; that sum must match the target |
| E2 | Use the official budget office score of how outlays (or deficits) change over the window |
| E3 | Use present-value (time-discounted) dollars |
| E4 | Match a percentage of baseline spending, not a raw dollar target |
| E5 | Other (you specify) |

### S — What counts as a cut
| ID | Meaning |
|----|---------|
| S1 | Only annual discretionary spending (the yearly appropriated part) |
| S2 | Discretionary **and** mandatory/entitlement changes |
| S3 | Do **not** count interest on the debt as a “cut” or as part of the balance |
| S4 | Do count estimated interest effects |
| S5 | Allow tax increases to count toward the “balance” (stretches “spending cuts”) |
| S6 | Explicitly ban timing tricks / gimmicks |
| S7 | Other |

### B — Forecast baseline
| ID | Meaning |
|----|---------|
| B1 | Current-law forecast (standard official baseline) |
| B2 | Current-policy forecast (assumes policies are extended — politically contested) |
| B3 | Administration forecast |
| B4 | Other named forecast |

### R — What the cuts must match
| ID | Meaning |
|----|---------|
| R1 | The face-value size of the debt-limit **increase** |
| R2 | Estimated extra borrowing room created by an increase **or suspension** |
| R3 | The whole projected decade deficit (usually much larger than a limit vote) |
| R4 | A fixed dollar number written into the bill, not tied to the limit size |
| R5 | Other |

### X — Exceptions
| ID | Meaning |
|----|---------|
| X1 | No exceptions |
| X2 | War / declared emergency exception |
| X3 | Exception if experts say default is imminent without a clean limit bill |
| X4 | Other |

## 3–5. Ranked packages

### Rank 1 — **P-Score-Strict**

**What this package concretely means:**  
Use the official current-law budget forecast. Count discretionary and mandatory spending changes as scored by the budget office. Do not count interest games. Ban timing gimmicks. Require the scored decade cuts to match either the face-value limit increase (if there is one) or — if you pick the suspension variant — the estimated borrowing headroom. No emergency skip. **Strict and relatively hard to game**; needs real scorekeeping.

**If chosen, the next phase can check:**  
Whether a concrete debt-limit proposal “balances” under this yardstick; whether “no balance” fails this **stipulated** test.

**It still cannot settle:**  
“Must,” “fiscally irresponsible” in an unrestricted sense, or “should not be enacted.”

**Relevance warning:** Partial overlap — turns the slogan into a checkable procedure, not a proof of the full claim.

**Objective claim-deviation assessment**  
1. **Strong-language preservation:** “Equal… over the following decade” becomes enforceable under a definite metric. “Spending cuts” preserved (taxes do not count). “Must,” “fiscally irresponsible,” and “should not be enacted” are **not** made enforceable by this lock alone (weakened to “fails this scorekept test if unpaired”).  
2. **Problem-identity check:** Still about pairing debt-limit action with decade spending cuts — **same proposition family**, operationalized. Does **not** substitute a general deficit-cap project.  
3. **Scope / baseline / metric shift:** Adds current-law baseline, CBO-style scoring, anti-gimmick, and interest exclusion — **not stated in the original claim** (necessary to make “equal cuts” definite).  
4. **Deviation summary:** **Moderate deviation**

**OR-slot if selected:** pick **R1** (numeric raise) or **R2** (suspension/headroom), or formally accept either.

### Rank 2 — **P-Score-CBO-Suspension**

**What this package concretely means:**  
Same strict scoring as Rank 1, but the match target is **borrowing headroom** (fits suspensions), and there **is** a narrow escape hatch if default is judged imminent without a clean bill. Slightly less absolute than Rank 1.

**If chosen, the next phase can check:**  
Balance under scored headroom rules; whether the default exception was invoked.

**It still cannot settle:**  
Unrestricted irresponsibility or “should not enact”; also cannot settle how often the exception would be abused.

**Relevance warning:** Partial — softens the original hard “must.”

**Objective claim-deviation assessment**  
1. **Strong-language preservation:** “Equal… decade… spending cuts” enforceable under scoring. “Must” **weakened** by default exception. “Irresponsible” / “should not” still not forced.  
2. **Problem-identity check:** Same pairing proposition, with an explicit governance exception — **not** a different topic, but not the absolute claim.  
3. **Scope / baseline / metric shift:** Same as Rank 1, plus R2 emphasis and X3 exception — exception **not** in original claim.  
4. **Deviation summary:** **Moderate deviation**

### Rank 3 — **P-Simple-Statutory**

**What this package concretely means:**  
Simple face-value dollars: discretionary cuts over 10 years must add up to the size of the limit increase, against a current-law-style forecast, no exceptions. **Easier to write into a short bill; easier to game** (narrow cut definition, no anti-gimmick rule, weak on suspensions).

**If chosen, the next phase can check:**  
Whether a bill’s discretionary totals nominally match a stated raise amount.

**It still cannot settle:**  
Serious fiscal-responsibility rhetoric; suspensions; mandatory spending; gaming; the normative “should not enact.”

**Relevance warning:** Partial — looks closest to bill prose, weak as economics.

**Objective claim-deviation assessment**  
1. **Strong-language preservation:** “Equal” and “decade” kept in a crude form. “Spending cuts” **narrowed** to discretionary-only (weakening). “Must” / “irresponsible” / “should not” not enforced by lock alone.  
2. **Problem-identity check:** Same pairing idea, thinner operationalization — still the same question family.  
3. **Scope / baseline / metric shift:** Discretionary-only and nominal sum are **stricter readings of silence** in the claim (claim did not say discretionary-only, but also did not forbid it). Poor fit for “suspension.”  
4. **Deviation summary:** **Moderate deviation**

**OR-slot:** best with **R1**; suspensions need R2 or this package misfits.

### Rank 4 — **P-Current-Policy**

**If chosen, the next phase can check:**  
Balance under that contested baseline — with big asterisks.

**It still cannot settle:**

**Relevance warning:** Partial / contested.

**Objective claim-deviation assessment**  
1. **Strong-language preservation:** Decade equal cuts operationalized; “must” weakened by emergency exception; irresponsibility/should-not not forced.  
2. **Problem-identity check:** Same pairing family, but baseline politics can dominate the substance.  
3. **Scope / baseline / metric shift:** Current-policy baseline and emergency exception **not** in original claim.  
4. **Deviation summary:** **Substantial deviation**

### Rank 5 — **P-Deficit-Match**

**What this package concretely means:**

**If chosen, the next phase can check:**  
Whether a package closes the decade deficit under scoring — a **different** fiscal project.

**It still cannot settle:**  
The original claim as a *debt-limit pairing* rule; it mostly abandons that scale.

**Relevance warning:** Weak overlap — easy to over-read as “more rigorous” while changing the question.

**Objective claim-deviation assessment**  
1. **Strong-language preservation:** “Equal spending cuts over the decade” kept verbally; link to “any debt limit increase or suspension” **dropped** in substance (target is full deficit). “Must/irresponsible/should not” not helped.  
2. **Problem-identity check:** **Substitutes** a general decade-deficit rule for a debt-limit pairing rule.  
3. **Scope / baseline / metric shift:** Reference amount shifts from limit action to full deficit path — **not licensed** by original claim.  
4. **Deviation summary:** **Problem substitution**
