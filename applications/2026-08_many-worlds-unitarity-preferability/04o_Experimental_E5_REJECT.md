# Candidate E5 — Separation, Audit, Red-Team, Admission

**Targets:** A1+A2 bridge (norm-as-weight)  
**Mode:** Experimental generation  

---

## 1. Rigid separation

### Pure unitary consequences (Schrödinger + already-admitted layers only)
- The Hilbert-space inner product / norm is part of the standard mathematical structure used to state unitary QM (L₀ formalism).
- Unitary maps preserve norms of state vectors.

### Added structure or idealizations (everything else)
- Interpreting norms of decohered components / branch amplitudes as **physical branch weights** or decision weights.
- Assuming a decoherence-defined decomposition into components to which those norms apply (**A1**).
- Equating “objective mathematical feature of the state space” with “not an epistemic posit” for probability.
- Using norm smallness as “negligibility” for branching without a probability concept (Wallace-style move) — still an importance criterion.

**Claim of E5:** Because \(\|\cdot\|\) is already in the QM formalism, treating squared norms as Born weights adds no epistemic postulate; A2 closes (and A1 is helped because decoherence uses the same objective norm).

## 3. Red-team pass

Strongest objections:
1. **Category error:** Presence of a mathematical norm does not license its probabilistic interpretation (E5.3).
2. **Redefinition:** E5.4 changes A2 from “no extra epistemic content” into “no symbol outside the Hilbert-space toolkit.”
3. **A1 dependency / circularity:** Needs components (E5.2); decoherence-importance debates loop with Born (E5.5).
4. **Silent posit:** The interpretation rule norm→weight *is* an epistemic/physical posit relative to bare unitary evolution of \(\lvert\Psi\rangle\).
5. **Does not remove Amb:** Even if norm is “already there,” the *mapping* to Born remains the free parameter.
