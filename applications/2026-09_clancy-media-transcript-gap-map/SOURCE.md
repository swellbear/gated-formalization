## 1. What a Rev page is (S0 target)

| Field | Value |
|-------|--------|
| Vendor class | **Rev** (and similar) **media / unofficial** trial transcripts |
| What the page *is* | A public, machine-aided unofficial transcript of a **media day** or **closings** audio/video — speaker labels, timestamps, `[inaudible]` markers |
| What the page is **not** | The **certified court-reporter record**. Not an official Massachusetts Superior Court transcript. Not a verdict. Not legal advice |
| Day page | One trial-day page (testimony / colloquy / exhibits as spoken on that media day) |
| Closings page | Argument + jury-instruction language. **Closings are argument / instructions, not evidence** |
| Honesty class | **Media≠official.** Speaker labels can be wrong. Words can be missed. Dates on the Rev page are **page stamps**, not a certified court calendar |
