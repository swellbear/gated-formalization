## 2. Agree (Agreement / Stability)

**Score:** Low → Moderate (unstable across careful readers)

**Notes on stability of reading across careful passes or reviewers:**

## 3. Prod (Productivity)

**Number of new, non-trivial, checkable consequences:** 2 (minimum-to-moderate pass if consequences are tied to a narrowed reading; weaker if left at full claim strength)

**List them:**
1. **Disruption / capacity prediction:** If a GWT-like workspace/bottleneck is doing real explanatory work, then interventions that selectively impair global availability within the model’s processing (e.g., severe context truncation, attention ablations that break cross-token integration, or forced fragmentation of shared residual stream information) should degrade “broadcast-like” cross-demand consistency (multi-constraint satisfaction, long-range coherence, report-of-internal-state tasks) more than purely local pattern completion — checkable in principle via controlled ablations.
2. **Scaling directionality:** If scaling strengthens the claimed correspondence, then as scale/context/integration increase, operational proxies of global availability (stability of a single coherent “currently active” task representation across tools/subtasks; reduced contradictory parallel “modes” under identical prompts; better ignition-like all-or-none success on globally demanding tasks) should improve *relative to* proxies of pure local specialization — checkable in principle if proxies are pre-registered.
3. *(Borderline / not counted as cleanly productive yet:)* “Models should exhibit reportability-like behavior tracking workspace capacity.” Too close to a paraphrase of access consciousness unless cashed out in distinct measurements beyond ordinary instruction-following.

**Scoring guide reminder:**  
- 0 → fails Prod  
- 1 → minimum pass  
- 2+ → strong Prod  

**Note:** Prod passes only for a *research-program* reading of the claim. It does **not** by itself make **(B)** admissible.
