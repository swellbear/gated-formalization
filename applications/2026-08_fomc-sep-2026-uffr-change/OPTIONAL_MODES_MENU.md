## 0. Plain-language framing

**What we’re doing:** Listing optional tools that *could* run if you authorize them. Not required to close examination.

**What we need from you:** Nothing unless you want one.

**What authorizing means:** Runs only that mode. Does not rewrite the ¢ census or turn not-established live shots into “unlikely.”

**What this does *not* mean:** Automatic Phase 2; that the FOMC will hike or hold; advice.

**How this differs from residuals:** Residual branches reopen a *scoped gap* on Rank 3 M3. Optional modes are separate tools (uses, contrastive alternatives, revise wording).
