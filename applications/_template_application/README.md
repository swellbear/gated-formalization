# Application Folder Template

Copy this entire folder to `applications/YYYY-MM_short-name/` for each new run.

Recommended contents after copying:

- `01_Anchor_and_ClaimType_Template.md` (filled)
- `02_Gate_Scoring_Sheet.md` (filled, including any re-scores)
- `03_Gap_Extraction_and_Ranking.md` (if Amb was high)
- `04_Material_Admission_Check.md` (one per candidate material examined)
- `notes.md` (optional free-form observations, residual judgment log, links to sources)
- `final_verdict.md` (short summary of outcome and remaining free parameters)

Keep descriptive claims and normative/strategic claims clearly flagged throughout.
