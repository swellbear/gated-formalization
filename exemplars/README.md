# Classical Sound-Argument Exemplars

Use historically successful arguments that closed important free parameters to **condition relevance judgment**. Exemplars are not automatic proof.

## Required record fields (per exemplar)

For each exemplar, record:
1. **Prior free parameter** — what was under-determined before the material was admitted
2. **Constraining material** — what closed or reduced that parameter
3. **Amb reduction** — what became constrained vs what remained free

## Starter categories

Expand these with concrete exemplar files over time:

1. **Developmental psychology** — constraints on innate vs. learned contributions
2. **Public-record / administrative procedure** — constraints on claims of government action
3. **Electoral geography** — constraints on claims of national political capture

## How to add an exemplar

Create a new markdown file in this folder (e.g. `YYYY-MM_short-name.md`) with the three required fields above, plus domain notes and links to sources. Keep selection judgment explicit: choosing an exemplar is itself a residual judgment point.
