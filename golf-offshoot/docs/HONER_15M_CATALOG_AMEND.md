# honer_15m catalog amendment protocol

**Family 3 is dated from files.** Three catalog items: `H-SKIP-RICH-YES`, `H-SKIP-WIDE-SPREAD`, then `H-SKIP-THIN-BOOK`. Palshi does **not** ping Lab. Palshi does **not** CoS-assign Lab. A later Lab refusal still stands. Soften Critic is a **later** session from the author of this amend, not this implement session.

This is **not** the factory 15m-3b skip-together idea (civil `:00` and `:30` together). That is a switched-off live-chair idea, not a Honer family.

A new family is not a tape sort, a pnl rank, or a Founder-free append.

## Order

1. **Files** — `library.json` `catalog_exhausted` and/or exam `completed_dead` make `HONER-FAMILY-AMEND` legal. The catalog dates the next family in file order (`H-SKIP-THIN-BOOK` is that third item). `latest/family_amend.json` stamps `owed` until the catalog has more than the original two items (`kind=taken` once dated).
2. **Operator** — RUN-ONLY on a later note if one is written. Does not ADMIT. Does not bind. Does not score.
3. **Soften Critic** — a **later** session from the author of the amend. Not this implement session. Not on the factory clerical whitelist.

File order **is** the picker. `catalog.next_family` walks `items[]` as written. Do not sort from the tape. Do not rank from pnl.

Lab is the **method** gate if they take a naming job (honesty, RUN-ONLY, they may refuse). Gym CoS is **not** required to seat Lab. Palshi does not ping Lab into it. “Don’t ping Lab” is not leave-idle: if the files already make the next family legal, date it from those files.

## Activate must be file-derived

`activate` is a named gate already on disk (`clip_exhaustion`, `quote_quality_ok`, `search_starvation`). It is not a discretionary switch.

Family 2 and family 3 may start when **either**:

- in-band clip exhaustion **and** quote completeness, **or**
- second search-starvation on the previous family **and** quote completeness.

The dated string is:

`clip_exhaustion+quote_quality_ok|search_starvation+quote_quality_ok`

`search_starvation` is a named reachability gate on the honer search clock. It is not a Founder-free family append. It does not revive a burned class. Soften Critic attacks this activate + rules amend in a **later** session.

Every item: `declared_at`, `id`, and `activate` (the first item may omit `activate`; that means start). Missing `declared_at` is a CatalogError.
