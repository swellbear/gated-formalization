# honer_15m catalog amendment protocol

**This build does not add a third family.** Two dated items only: `H-SKIP-RICH-YES` then `H-SKIP-WIDE-SPREAD`.

A new family is not a tape sort, a pnl rank, or a Founder-free append.

## Order

1. **Lab** — dated PROPOSED in a later session. Names the family id, knob, start, clip, step, and the file-derived `activate` (today: `start`, `clip_exhaustion`, `quote_quality_ok`, `search_starvation`, `clip_exhaustion+quote_quality_ok`, `search_starvation+quote_quality_ok`, or an `|` of those named gates).
2. **Operator** — RUN-ONLY on that note. Does not ADMIT. Does not bind. Does not score.
3. **Soften Critic** — a **later** session from the author of the PROPOSED. Not this implement session. Not on the factory clerical whitelist.

File order **is** the picker. `catalog.next_family` walks `items[]` as written. Do not sort from the tape. Do not rank from pnl.

## Activate must be file-derived

`activate` is a named gate already on disk (`clip_exhaustion`, `quote_quality_ok`, `search_starvation`). It is not a discretionary switch.

Family 2 may start when **either**:

- in-band clip exhaustion **and** quote completeness, **or**
- second search-starvation on skip-rich **and** quote completeness.

The dated string is:

`clip_exhaustion+quote_quality_ok|search_starvation+quote_quality_ok`

`search_starvation` is a named reachability gate on the honer search clock. It is not a Founder-free family append. It does not revive a burned class. Soften Critic attacks this activate + rules amend in a **later** session.

## Burn list (refuse these ids)

FLIP, PERSIST, SEAS-DIR, SHRINK, LOGIT, RETUNE-COINFLIP-BAND, FEE-AS-SIGNAL, SUM-LINEAGES, BACKFILL-GAP, BASELINE-AS-EDGE.

`catalog.py` rejects a burned id. Do not revive them under a new spelling to skip this list.

## Required fields

Every item: `declared_at`, `id`, and `activate` (the first item may omit `activate`; that means start). Missing `declared_at` is a CatalogError.

## This build

Does **not** add a third item. Does not score, bind, or arm. Search starvation is honer-only; it does not become a factory selection rule.
