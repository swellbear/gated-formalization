# Known limitations

- **v1 pricing is provisional.** Terminal-spot Monte Carlo with one σ. Not a full vol surface. Ranges are snapshot uncertainty, not a proof.
- **Polygon is the frozen quote vendor.** If the key or plan lacks a calendar, earnings uses the frozen ticker file — still a leash, not “relevant stocks.”
- **Frozen S&P-style file is not a live index reconstitution.** Expand only via method law.
- **Illiquid strikes stay n/a.** Listed ≠ available. Do not invent a bid from last.
- **Honesty ≠ better.** B-guts can lose more paper.
- **Index is a map.** Shopping the fattest table is forbidden.
- **No hunter in v1.** Agronomy-equivalent (news, blogs, “should be in”) stays unconstrained.
- **Does not import GPF or golf-offshoot.** Does not auto-trade.
- **IBKR venue ask is not v1.**
- **Settle is expiry.** Marks are not the result.
- **n=1 tape.** Do not move `t` from one expiry.
