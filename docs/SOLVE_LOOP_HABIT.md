# Name the missing piece, invent a check, stop when the fog does not move

A short working habit. It does not change how claims are scored.

## The habit

- Name **one** concrete missing piece — the fog you actually cannot see through. Not a slogan. Not a pile of maybe-gaps.
- Invent a **check** that could answer or clear that piece. This is not another lookalike horse. If the check cannot kill or harden that named gap, invent something else.
- Run it **cheap**.
- After the run: either the fog shrinks, or that missing piece was the wrong one. Then pick the **next** piece.
- Stop when new checks only restate the same FRAGILE / still-foggy result.

You **may** use **targeted research** when inventing the check: propose **2–3 ranked options** for that *named* missing piece only. For each option say why it could clear that fog, the rough cost, and whether a result would kill vs harden the gap. Do **not** default to an extensive literature survey. Research designs a better check; it does **not** replace running one. A literature summary with no probe is not a solve step — that is search-as-solve, and it does not count.

Tiny practice or training runs can stay light.

## How to score an invent

Score it on “did this kill or harden a named gap?” — not on how many horses you minted.

## No fake clears

The **Operator** admits, rejects, or parks. Lab invents and tests. Lab never admits its own candidate.

A cheaper question is not a cleared claim. Lower Ambiguity is not clearance. Burned classes stay burned. This habit does not rewrite the admit rules.

## Why

Honesty and naming Ambiguity are not enough if every invent is a lookalike direction horse. Problem-solving is first-class: name the fog, invent a check that could move it, stop when the checks stop moving it.
