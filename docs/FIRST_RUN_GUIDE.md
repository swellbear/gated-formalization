# First Run Guide — Walking Through One Simple Claim

This walkthrough is for a first-time user. Read [`PLAIN_LANGUAGE_OVERVIEW.md`](PLAIN_LANGUAGE_OVERVIEW.md) first. When a technical term appears, its everyday meaning is in [`GLOSSARY.md`](GLOSSARY.md).

We will use one lightweight example:

> **The Main Street post office is open to the public on Saturday mornings.**

Nothing high-stakes. The point is to practice the [Lean Default Path](GLOSSARY.md#lean-default-path) (the usual lighter route) with heavy explanation and light process.

Whenever the method asks you to choose, options appear **in this chat** as clickable **A / B / C** choices, each with a short plain-language explanation. Click the option — that click is the reply.

---

## 0. What success looks like at the end

A successful first **hard stop** (examination finished and the write-up sealed) usually looks like this:

- You can say in ordinary words what you tested.
- You listed a few hard-to-dispute starting facts ([anchors](GLOSSARY.md#anchor)).
- You said whether this is a fact-claim or a should-claim ([claim-type](GLOSSARY.md#claim-type-descriptive--normative--mixed)).
- You scored the claim once ([gate scoring](GLOSSARY.md#gate-scoring)).
- If something important was still unset, you named at most one or two leftover choices ([gaps](GLOSSARY.md#gap)) and maybe admitted one source ([material admission](GLOSSARY.md#material-admission)).
- You did **not** treat “we made the question clearer” as “therefore yes.”
- Leftovers, if any, are parked with an explicit trigger (for example: “reopen if the posted Saturday hours change”).
- The verdict is often **provisional** (well-posed with limits, not a full slogan clearance). That is a good first run.

---

## 1. Anchors and claim-type

**What you are doing:** Write down facts you are not going to argue about, then say what kind of sentence this is.

**Why:** If “open” or “Main Street” can mean several things, later scoring is theater.

On the Anchor sheet (`templates/01_Anchor_and_ClaimType_Template.md`):

- Anchors might include: there is a USPS facility people call the Main Street post office; “Saturday morning” is a clock window; “open to the public” means a customer can complete ordinary counter business, not merely that a building exists.
- Claim-type: **Descriptive** (about how the world is). There is no “should” in the sentence.

You are not yet proving Saturday hours. You are making the question fair.

---

## 2. Import relevant locks, then check Consistency

**What you are doing:** See whether this toolkit already froze a meaning that applies, and check it does not clash with *these* facts. Do this *before* the first full scoring pass.

**Why:** Reusable [locks](GLOSSARY.md#lock) save work, but they are never automatic.

For this toy claim you may import nothing, or only a general reminder such as: lowering how unset the question is does not prove the hours. Record “none imported” if that is honest. Then a [Consistency](GLOSSARY.md#consistency-cons) note: the claim does not contradict the anchors.

---

## 3. First gate scoring

**What you are doing:** Fill `templates/02_Gate_Scoring_Sheet.md` once, with the imported decisions in mind.

**Why:** You want an inspectable first picture, not a vibe.

In plain terms you will ask:

- Does it clash with the anchors? ([Cons](GLOSSARY.md#consistency-cons))
- Would two careful readings of the *same* frozen sentence agree? ([Agree](GLOSSARY.md#agreement-agree) — secondary)
- Does it imply any new checkable consequence you did not already assume? ([Prod](GLOSSARY.md#productivity-prod) — secondary)
- What is still unset? ([Amb](GLOSSARY.md#ambiguity--under-determination-amb) / [free parameters](GLOSSARY.md#free-parameter))

Typical leftovers here: *which* Saturday (this week vs always); lobby vs box lobby vs 24-hour kiosk; whose hours page counts as the live source.

**Remember:** a smaller Amb number means the question is clearer. It does **not** mean the post office is open.

If Amb is already low *and* a live hours source is in, you might be ready to stop. If Amb is still high, continue — but only the top leftovers.

---

## 4. If still unclear: attack only the top 1–2 gaps

**What you are doing:** On `templates/03_Gap_Extraction_and_Ranking.md`, name the leftover choices and rank them. Then work only the top one or two.

**Why:** The Lean Default Path refuses to open every nearby post-office question (staffing, wait times, “usually”).

A freeze line might be: “Open = counter service available to walk-in customers on the next Saturday morning, 8:00–12:00 local, at the named Main Street facility.”

You are deciding what the test *is*, not yet looking up hours.

---

## 5. At most one or two admission cycles

**What you are doing:** Find a source aimed at those gaps. Run `templates/04_Material_Admission_Check.md`.

**Why:** A blog saying “small-town post offices are sleepy on weekends” is a different question. The official location’s posted Saturday hours, if they match the freeze, are on-point.

Admit only if the source actually constrains the gap **and** stays consistent with the anchors. If the page is marketing copy, or the URL is a different branch, reject or hold. Write down any [residual judgment](GLOSSARY.md#residual-judgment) (the human call the sheet cannot make).

Then re-score. If Amb is no longer the problem, stop. Do not keep hunting for a more satisfying “yes.”

---

## 6. Default endpoint

**What you are doing:** Close as **provisional** with leftovers parked, or seal a **hard stop** when the write-up is done.

**Why:** Ordinary claims should not grow a second textbook. Deeper leftover-branching is for high leftover Amb *plus* a leftover that looks realistically constrainable, or unusually high stakes. This post-office sentence is not that.

A compact park might be: “If USPS changes the posted Saturday window for this ZIP, reopen.” That trigger is explicit. It is not a hidden “therefore open.”

---

## What a successful first hard stop looks like

You can hand someone a short note:

- Claim tested: Main Street post office, public counter, next Saturday morning.
- Starting facts listed; type = descriptive.
- Locks imported: none (or named).
- One scoring pass; at most one or two sources checked.
- Result: either the posted hours support the frozen reading, or they do not, or the live page was missing and the leftover is parked.
- You did **not** say “we defined it carefully, so it must be true.”
- File sealed; optional extra tools offered, not auto-run.

That is a complete first run. Precision stayed. The process stayed light.
