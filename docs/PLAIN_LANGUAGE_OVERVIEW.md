# How This Method Works (For a New User)

This method examines a claim so you can tell what is actually supported, what is still unclear, and what would have to be true before anyone should treat the claim as settled. It exists because ordinary argument often jumps from a slogan to a confident “yes.” The toolkit slows that jump without pretending paperwork can replace judgment.

## The normal path a claim follows

Most new claims should follow this lighter sequence (the Lean Default Path — the usual route unless the claim is unusually important or still very unclear):

1. **Write down hard facts and say what kind of claim this is.** List points that are difficult to dispute (anchors). Say whether the claim is about how the world is, about what someone should do, or both.
2. **Bring in earlier decisions that already apply, and check they still fit.** If this toolkit has already frozen a meaning on a similar problem (a lock: an explicit freeze of what a word means), import it and check it does not clash with this claim’s facts — *before* the first full scoring pass.
3. **Score the claim on a few gates.** Ask: does it contradict the facts? How many important meanings are still unset? Making the question clearer is *not* the same as proving the claim.
4. **If it is still very unclear, name the top one or two gaps.** A gap is a leftover choice that still has to be fixed before the claim is well posed. Work those first; do not open every side question.
5. **Look for at most one or two pieces of real material** that could close those gaps. Admit a source only if it actually speaks to the gap *and* does not contradict the facts you already listed.
6. **Default stop:** close as provisional (well-posed with limits, not a full “yes”) and park leftovers with a clear trigger, or seal a hard stop once the write-up is finished.
7. **Go deeper only when needed.** Extra sheets are for when the claim is still very unclear *and* a high-impact leftover looks constrainable, or the stakes are unusually high.

## What the method is careful about

The method refuses easy “yes” answers because a clearer question is not the same as a true claim. Fixing meanings or finding another source that prints the same number can tidy the work without showing the original slogan is established. If important choices are still open, the honest result is usually “not yet well constrained” — not “therefore false,” and not “close enough.” Human calls about relevance stay on the record instead of hiding in a score.

## What you will be asked to decide

You still decide. All choices appear in this chat as clickable A / B / C options, each with a short everyday sentence. Click the option — that is your answer.

- What the claim is actually saying, in words you would use out loud.
- Whether it is a fact-claim, a should-claim, or mixed.
- Which earlier frozen meanings, if any, apply here.
- Which one or two unclear parts to tackle first.
- Whether a source really answers *that* part, or a nearby different question.
- When to stop and park leftovers versus keep searching.
- Whether to keep the original wording on the record.

Reusable locks make later claims easier because you do not have to re-argue the same meaning every time. They are never applied automatically: each new claim still has to check that the imported decision fits its own facts. Precision stays. The paperwork should not be a wall.
