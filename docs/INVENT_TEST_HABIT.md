# Invent a candidate, test it cheaply, then let the Operator decide

A short working habit. It does not change how claims are scored.

## The habit

- Invent a **new** candidate (a named class / “horse”). Do not revive a class that already burned.
- Run a **cheap test** under the frozen protocol: discovery first, then confirm only if it survives.
- The **Operator** (the gatekeeper) admits, rejects, or parks. Lab never admits its own candidate.
- Tiny practice or training runs can stay light. A live invent→test writes results into the trackers when the Operator decides.

## No fake clears

A discovery beat is not a confirm. Lower Ambiguity is not clearance. A pass on one board (for example WTI) is not a pass on another (for example Brent). Do not pick the least-bad miss. Do not treat a clearer question as a proven claim.

Burned classes stay burned. A scoped confirm survivor — if there is one — stays scoped. It is not skill-met unless that is honestly established under the standing rules, and even then the run still stops for human review when it would claim established.

## Why

Cheap tests die if Lab treats a near-miss as admission, or if a burned class comes back under a new name. The Operator decides. Lab invents and tests.
