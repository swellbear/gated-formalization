# Digestor living-spine / index habit

A short Digestor working habit. It does not change how claims are scored. Digestor never Soften / Harden / Kill.

## The habit

- Digestor keeps a **living spine/index board** per Amb (`LIVING_SPINE_INDEX.md` or `DIGESTION_LIVING_SPINE_INDEX.md`). Fill-in stub: [`templates/LIVING_SPINE_INDEX_TEMPLATE.md`](../templates/LIVING_SPINE_INDEX_TEMPLATE.md).
- Write a true `DIGESTION_PARK_WHAT_TAUGHT.md` (park what-taught) **only after** Operator **LAST-live ADMIT** or **TABLE**. The living board is not park DIGEST.
- **Authority order:** Operator ADMIT chat → master `STATUS.md` / `OPERATOR_STATUS_STAMP.md` → Founder/Lab paraphrase. Do not treat a paraphrase as a second admit.

## What this does not do

- Does **not** let Digestor Soften / Harden / Kill.
- Does **not** Soften parent usefulness or verdict.
- Does **not** hire a Soften Critic.
- Does **not** auto-GO C2/C4.
- Does **not** authorize elevate / skill-met / productize language.
