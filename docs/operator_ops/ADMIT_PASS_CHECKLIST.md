# Admit-pass checklist (full, 9 steps)

Habit §E–H. Short stub: [`templates/OPERATOR_ADMIT_PASS_CHECKLIST.md`](../../templates/OPERATOR_ADMIT_PASS_CHECKLIST.md).

Run this on every Operator Soften / Harden / Kill / dated-record / park ADMIT **and** on every idle-breach REJECT. Same pass: Softened SoT **then** docs fold. Do not wait for a second Founder ping.

## The nine steps

1. **Read first.** Open the Operator STATUS stamp, `SOFTENED_SET.md`, and the idle latch before any admit language. Chat Softened lists are not carry.

2. **Name the board and the Founder call.** Dated record / PROPOSED / park. Founder GO / reject / still open. If the call is still open, that is the only time **HOLD Soften** is legal.

3. **Classify.** Stamp exactly one of ADMITTED / REJECTED / PARKED / HOLD Soften (REJECTED/PARKED may pair). See [`STATE_VOCAB.md`](STATE_VOCAB.md).

4. **Idle latch.** If idle is ON, any new Lab PROPOSED is **REJECT as idle-breach** (**not Softened**). Soften Hard NO. Do not clear idle. See [`IDLE_LATCH.md`](IDLE_LATCH.md).

5. **After Founder reject.** Stamp **REJECTED/PARKED**. Never HOLD Soften pending GO. Lab waiting Soften on REJECTED is an Operator **hard-stop**.

6. **On dated-record ADMIT, write SoT.** Box-lab twin if mid-run; always update `SOFTENED_SET.md` and the stamp. **Edge Softened/established?** defaults to **N** on ops tracks. See [`OPS_BESIDE_METHOD.md`](OPS_BESIDE_METHOD.md).

7. **Launch the docs fold in this same pass.** Do not wait for a second Founder ping. Record **Docs fold PR#** and **both** Softened SoT paths (box-lab + master). See [`DOCS_FOLD_LATENCY.md`](DOCS_FOLD_LATENCY.md). If a prior fold is in flight, queue (habit §A) — still in this pass.

8. **Honesty / Hard NOs.** No elevate / skill-met / productize. Usefulness / verdict **NOT** Softened this fold. No auto-GO C2/C4. Soften Critic **not** hired. Digestor / Lab never Soften / Harden / Kill (`lab_admits=false`). Ops tracks: no banked-edge, invent finishes, demo-as-edge, or cash deposit-withdraw. Include [`templates/SOFTEN_PR_HONESTY_CHECKLIST.md`](../../templates/SOFTEN_PR_HONESTY_CHECKLIST.md) on the PR.

9. **Auto-merge docs-only CLEAN.** Mark ready if draft, then squash-merge. Master Softened SoT path is post-fold authority. Digestor / Lab treat master stamp + Softened_SET as carry — do not re-ask for a second admit.

## What this is not

- Not a Material Admission Check or Amb scoring change.
- Not a Soften Critic hire.
- Not a usefulness / verdict Soften.
- Not an auto-GO of C2/C4.
