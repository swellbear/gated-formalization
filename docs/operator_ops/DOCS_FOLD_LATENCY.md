Dated-record ADMIT is not finished in chat. The Operator writes the Softened source of truth and launches the docs fold in the **same pass**.

## Same-pass order

On dated-record **ADMIT**:

1. Write Softened SoT (box-lab twin if the run is mid-flight; see [`OPS_BESIDE_METHOD.md`](OPS_BESIDE_METHOD.md)).
2. Update `SOFTENED_SET.md` and the Operator STATUS stamp (incl. Docs fold PR# once opened; both Softened SoT paths).
3. Launch the docs-fold PR **now**.

Do **not** wait for a second Founder ping to start the fold. The ADMIT *is* the authorization to fold.

## Auto-merge docs-only CLEAN

When the fold is **docs-only** and the honesty checklist is **CLEAN**:

1. Mark the PR **ready** if it is still draft.
2. **Squash-merge**.

Do not leave a CLEAN docs-only fold sitting as draft waiting for another Founder “merge it” line.

## Lane still one-at-a-time

Habit §A still holds. If a prior Soften fold is in flight, **queue** this fold until that PR is CLEAN + squash-merged (or closed). Queuing is not waiting for a new Founder ping. The Operator starts or queues in this pass.

Tiny VIZ-pointer-only amends stay under §A’s exception.

## What this is not

- Not a scoring change.
- Not a Soften Critic hire (the critic is already hired; same-pass fold does not hire it).
- Not an elevate / skill-met / productize license.
- Not permission to open a second parallel Soften PR for the same Amb.
