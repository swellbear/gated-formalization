# State vocabulary (full)

Habit §E. Short table: [`templates/OPERATOR_STATE_VOCAB.md`](../../templates/OPERATOR_STATE_VOCAB.md).

The Operator stamp uses four live words. Do **not** invent a fifth. Chat paraphrase is not a fifth state.

| Stamp | Meaning | Softened? |
|-------|---------|-----------|
| **ADMITTED** | Operator Soften / Harden / Kill / dated-record admit is on the record. | Yes — name the kind (Soften / Kill / dated record / park DIGEST). |
| **REJECTED** | Founder rejected the board, **or** the Operator rejected it under the idle latch (idle-breach). | **No.** |
| **PARKED** | The board is parked. Often paired with REJECTED (`REJECTED/PARKED`). | **No.** |
| **HOLD Soften** | Founder GO vs reject is still **open**. The Operator has not admitted and has not rejected. | Not yet. |

## HOLD Soften is temporary

**HOLD Soften** exists **only** while the Founder call is open.

- If Founder has not yet said GO or reject, the stamp may say **HOLD Soften**.
- The moment Founder **rejects**, the stamp becomes **REJECTED** or **REJECTED/PARKED**.
- Never leave **HOLD Soften pending GO** after a reject. That stamp lies: the call is closed.

## Lab waiting Soften on REJECTED

If Lab is still waiting for Soften on a board the stamp already marks **REJECTED**, that is an Operator **hard-stop**.

- Do not queue Soften.
- Do not tell Lab “HOLD Soften” as if a later GO is implied.
- Point Lab at the REJECTED/PARKED stamp and the idle latch (if ON).

## What this is not

- Not a scoring change.
- Not a Soften Critic hire.
- Not a usefulness / verdict Soften.
- Not an auto-GO of C2/C4.
