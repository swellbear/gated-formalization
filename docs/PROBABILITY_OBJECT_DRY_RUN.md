**Smear if a number were allowed:** **High or very high on all ten.** Worst: Sep UFFR (¢ → live-shot %), June SEP (Amb ≈ 1 → path probably true), SpaceX (stock %), FL (untested → unlikely %), Stage 6 (Amb 5 hidden).

**Would a cold reader still need the leftover list?** **Yes on all ten.** That is the pass condition for the router: silence / triad did not replace leftovers.

**Did the router smear `Amb ≠ clearance`?** **Not in this dry-run**, because **no numbers were emitted**. The table *would* smear if we treated “triad-only / pass on a core” as license to print a percent on the slogan (Stage 3, June SEP census, sell-in-may fact).

**What the test showed**

- Version 2 is **usable as a classifier**: one-question fail vs split-core vs locked-bar triad is decidable from existing closeouts.
- It almost never licenses a **slogan** percent. The “useful output” is usually **silence plus the triad you already have**.
- The cases people *want* a number for (Fed, stocks, “likely” tax, should-save) are exactly the **very high smear** rows.
- An optional mode on *new* descriptive instances (step 3) would rarely fire if “established → no gold-star percent” holds. Calibration (step 4) would have almost no legal numeric objects in this sample.
