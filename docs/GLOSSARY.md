# Glossary — Plain English Definitions

Short definitions for a first-time reader. Partner closeout terms (established, share pack, and similar) live in [`READER_GLOSSARY.md`](READER_GLOSSARY.md). Method overview: [`PLAIN_LANGUAGE_OVERVIEW.md`](PLAIN_LANGUAGE_OVERVIEW.md).

## Anchor

A hard-to-dispute starting fact or constraint you are willing to treat as given for this run (for example, a published date, a legal text, or a basic physical fact).  
**Why it matters:** Later layers are checked against these starting points so the argument cannot quietly contradict what you already accepted.

## Claim-type (Descriptive / Normative / Mixed)

A label for what the claim is doing: **Descriptive** is about how the world is; **Normative / Strategic** is about values, “should,” or advocacy; **Mixed** has both and must be split.  
**Why it matters:** A fact check and a “should” recommendation are different jobs; mixing them without splitting hides which part failed.

## Consistency (Cons)

Whether the claim, as you are reading it, clashes with the anchors or with layers already admitted.  
**Why it matters:** If it contradicts accepted facts, it should not be carried forward as if those facts still hold.

## Agreement (Agree)

Whether careful re-readings of the *same* constrained claim actually settle on the same meaning, rather than sounding fluent.  
**Why it matters:** Smooth wording is not the same as a stable reading; this gate is secondary and should not be inflated by confidence.

## Productivity (Prod)

Whether the claim yields new, checkable consequences that were not already licensed by what you have admitted.  
**Why it matters:** Restating the slogan or listing hoped-for results does not count; this gate is secondary.

## Ambiguity / Under-determination (Amb)

How many important leftover choices (free parameters) still have to be fixed before the claim is well posed.  
**Why it matters:** Lower Amb means the question is clearer. It does **not** mean the claim is true or that a “likely / potential” bar has been met.

## Free parameter

An important meaning, scope, number, or source that is still unset or under-specified.  
**Why it matters:** Unset choices are why a claim can sound decisive while still being able to mean several different things.

## Gate scoring

A structured pass that scores Consistency, Agreement, Productivity, and Ambiguity, then records a verdict.  
**Why it matters:** It makes the first “how strong is this?” judgment inspectable instead of a vibe.

## Gap

A named leftover choice that is driving high Ambiguity or blocking admission.  
**Why it matters:** Search is aimed at a specific gap so you do not wander into a nearby, easier question.

## Material admission

A formal check of whether a candidate source actually constrains the targeted gap and stays consistent with the anchors.  
**Why it matters:** Interesting reading is not automatically allowed in; only material that passes relevance plus Consistency is admitted.

## Lock

An explicit decision that freezes a meaning (what counts, what is being measured, which bar height) before further testing.  
**Why it matters:** Locks make later tests fair. They are never automatic, and freezing a meaning is not the same as proving the claim.

## Bar height (`P-Logical` / `P-NonNegligible` / `P-BaseCase`)

How strong the claim *means*: merely possible / real shot / expected path. Partner copy uses those everyday words. The `P-*` IDs are operator labels in the technical table — **not** a probability that the slogan is true. See [`READER_GLOSSARY.md`](READER_GLOSSARY.md).  
**Why it matters:** Hearing “P-NonNegligible” as “the probability” mixes a meaning-lock with a forecast.

## Residual judgment

A human call that the worksheets cannot make for you (for example, whether a source is really on-point).  
**Why it matters:** The method keeps those calls visible instead of burying them in a score.

## Provisional

A verdict that the claim is well-posed enough to continue or close with limits, not a full unrestricted “yes” to the original slogan.  
**Why it matters:** Most honest runs end here; provisional is not a polite word for “true.”

## Hard stop

Examination of this claim is finished **and** the write-up hygiene is done (the record is sealed as stated).  
**Why it matters:** It tells you the file is closed for this wording; leftovers may still be parked until a named trigger, which is not the same as proving the slogan.

## Lean Default Path

The recommended lighter sequence for most new claims: anchors and claim-type, import relevant locks and check Consistency, first gate scoring, at most the top one or two gaps, at most one or two admission cycles, then a default provisional close unless deeper work is truly warranted.  
**Why it matters:** It reduces process weight on ordinary claims without relaxing the ban on easy “yes” answers.
